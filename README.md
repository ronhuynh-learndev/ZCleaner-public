# ZCleaner

ZCleaner giúp bạn xem trước và dọn các tệp Zalo lưu trên máy Mac hoặc Windows. Bạn chọn phạm vi quét và xác nhận trước khi dọn; ứng dụng ưu tiên chuyển tệp vào Thùng rác để có thể khôi phục.

ZCleaner hoạt động độc lập, không cần đăng nhập và không liên kết với Zalo. Tên tệp, đường dẫn và nội dung tệp không được gửi ra ngoài.

## Tải ZCleaner 1.0.0

Tải bản phù hợp với máy tại [Release v1.0.0](https://github.com/ronhuynh-learndev/ZCleaner-public/releases/tag/v1.0.0):

| Máy | Chọn file |
| --- | --- |
| Mac dùng chip Apple Silicon | `ZCleaner-v1.0.0-ARM.dmg` |
| Mac dùng chip Intel | `ZCleaner-v1.0.0-Intel.dmg` |
| Windows 64-bit | `ZCleaner-v1.0.0-windows-x64.zip` |

Trên Mac, mở DMG rồi kéo ZCleaner vào Applications. Trên Windows, giải nén toàn bộ ZIP rồi mở `ZCleaner.exe` trong thư mục vừa giải nén. Các lưu ý khi mở và mã SHA-256 nằm ở trang Release.
